# Code of conduct

Shannon Prover follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
We want this project to be a welcoming, respectful, and harassment-free place
for everyone who takes part in it.

Please report unacceptable behavior to **shannonprover@gmail.com**. Reports
are handled by the project maintainers and kept confidential.
